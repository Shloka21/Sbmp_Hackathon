# 🎮 Finance Quest: Needs vs Wants

## How to Run
```bash
cd /Users/vineetkumarshah/Hackathon/game/finance-quest
python3 main.py
```

---

## 🎯 Game Objective
Learn the difference between **NEEDS** (essential) and **WANTS** (nice-to-have) by managing a budget over 3 days.

---

## 📋 How to Play

### Day Flow:
1. **Mom gives shopping list** → These are today's NEEDS
2. **Play Match-3 game** → Earn coins by matching gems
3. **Shop** → Buy items (needs are green ✅, wants are red ❌)
4. **Go Home** → Press H to return to Mom
5. **Evaluation** → Mom checks if you bought the NEEDS
6. **Repeat** → 3 days total

---

## 🕹️ Controls

| Screen | Key | Action |
|--------|-----|--------|
| **Menu** | ↑ ↓ | Navigate options |
| **Menu** | Enter | Select |
| **Match-3** | Mouse Click | Select gem |
| **Match-3** | Click adjacent gem | Swap to match 3+ |
| **Shop** | ↑ ↓ | Browse items |
| **Shop** | Enter | Buy selected item |
| **Shop** | **H** | Go Home (done shopping) |
| **Any** | Enter | Continue to next screen |

## 🏆 Scoring
- ✅ Each correct NEED bought = **+30 points**
- ❌ Each WANT bought = **-10 points**
- 🌟 Perfect day (all needs, no wants) = Bonus!

> **NEEDS come before WANTS!**
> Always budget for essentials first.
